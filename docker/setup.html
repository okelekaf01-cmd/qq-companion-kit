让她先说上第一句话。

容器已安装。下面三步分别处理 QQ 登录、模型凭据和聊天范围，按顺序完成。

1. 登录机器人 QQ

打开 NapCat 管理页，用专门的小号扫码，手机上确认登录。二维码过期后，在页面刷新二维码。

如登录后令牌变更或提示强制改密，以 NapCat 当前页面和日志为准。安装器不会覆盖已存在的管理配置。

2. 给模型填写 API Key

打开 DeepSeek Harness，进入设置的模型配置，填写自己的 DeepSeek API Key 并保存。随后在 DSH 内试一次简短对话，确认模型可用。

API 按调用计费。只在 DSH 的模型设置中填写密钥，普通 QQ 消息不会帮你完成密钥配置。带登录凭据的管理链接也要保密。

3. 指定谁可以聊天

管理 QQ 和机器人 QQ 是两个账号。保存前会话默认全部拒绝。保存会替换管理 QQ 和整份聊天白名单。

4. 用另一账号发一条消息

先加机器人 QQ 为好友，再用上面填写的管理 QQ 发“你好”。收到回复后，进入 QQBridge 控制台，编辑角色、查看用量或调整主动发言。

NapCat 在线、桥接已连接和收到真实回复是不同的检查。页面打开成功只说明管理服务可访问。
